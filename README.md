## 制作背景
大学3年の春休みに、就職活動で自分の強みとして示せる作品を作りたいと考え、以前から興味のあったゲーム制作に挑戦しました。

## 使用技術
- Unity
- C#
- GitHub

## 機能一覧
- タップによるジャンプ操作
- ランダム障害物生成
- スコア計測
- リプレイ機能
- タイトル画面遷移

## 製作期間
- 約24時間（設計・実装・デバッグ含む）

## 工夫した点
- 年齢問わずプレイできるように、タップのみの簡単操作にした
- 障害物が一定間隔ではなくランダムに出現するようにし、プレイごとに異なる体験ができるようにした
- UIをシンプルにした
- 未就学児でもゲームに対して嫌悪感を抱かないように、デザインをポップにした
- ゲームに集中できるように色を白と青の2色に限定した

## 苦労した点
障害物をランダムな位置に生成する機能の実装に苦労しました。
当初は独自に考えた方法で実装を試みましたが、障害物が重なって出現したり、画面外に生成されたりする問題が発生しました。
そこで、Unityでゲーム制作を行っている方の動画や生成AIを活用しながら原因を調査し、生成座標のデバッグを行うことで問題を解決しました。

## 学んだこと
- Unityを用いたゲーム開発の基礎
- C#によるオブジェクト制御
- エラー発生時の調査・解決方法

## 今後の改善点
- 開始ボタンを押すと同時にジャンプするようにする
- データベースでのスコアの保持
- 障害物の出現頻度を調整できる設定機能
- BGMのON/OFF機能
